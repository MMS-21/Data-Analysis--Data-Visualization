## 📊 Project Overview

This dashboard translates complex workforce data into actionable insights to improve retention strategies. Using a sample dataset of over **1,400 employees**, it allows executives to visualize patterns in attrition, helping specific departments target high-risk groups.

## 🔍 Key Insights & Findings

Based on the analysis of the executive and deep-dive views, the following trends were identified:

- **⚠️ High-Risk Roles**: `Sales Representatives` show the highest attrition rate at **40%**, significantly higher than the company average of **16%**.
- **💰 Financial Impact**: There is a clear correlation between pay and turnover. "Leavers" have an average monthly income of **$4,787**, compared to **$6,833** for those who stay.
- **📉 Demographic Trends**: The **18-25 age group** experiences the highest attrition at **57%**, suggesting a need for better early-career engagement initiatives.
- **⚖️ Work-Life Balance**: Employees working **Overtime** have a **23%** attrition rate, highlighting burnout as a potential turnover factor.

## 🛠️ Features

### 1. Executive Summary

High-level KPIs designed for quick decision-making:

- Total Leavers (237)
- Average Tenure (7 years)
- Overall Attrition Rate (16%)

### 2. Deep-Dive Capabilities

Interactive filters to isolate specific cohorts and analyze data by:

- Gender
- Age Group
- Overtime Status
- Job Role

### 3. Satisfaction Analysis

Comparative metrics showing that "Leavers" consistently report lower job satisfaction (**2.5/4**) than "Stayers" (**2.8/4**).

### 4. Cross-Departmental Comparison

Visual breakdown of turnover across **Sales**, **R&D**, and **Human Resources** to pinpoint departmental issues.

## 📂 How to Use

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/yourusername/ibm-hr-analytics.git
    ```
2.  **Open the File**
    - Locate the `.xlsx` file in the downloaded folder and open it with Microsoft Excel.
3.  **Explore the Dashboard**
    - Navigate between the **Executive View** and **Deep-Dive View** using the navigation arrows in the top corners.
